Landing page en italiano para promocionar un viaje de un día al Oktoberfest, con salida desde Milán/Bérgamo. Diseñada y desarrollada en WordPress con Elementor.

🔗 **Demo en vivo:** https://leonardocorpus.github.io/Gbravo/

## Qué hice
- Portada con imagen de fondo, título destacado y botones de llamada a la acción ("Acquista ora!" y "Vedi itinerario")
- Etiquetas informativas del viaje (transporte, acompañante, seguro médico, horarios)
- Sección con contador regresivo y mensaje de cupos limitados
- Botón "Parla con un agente" conectado a WhatsApp
- CSS personalizado con degradados naranja-rosa y estilos de botones
- Diseño responsive (escritorio, tablet y móvil)
- Exporté el sitio a HTML estático con Simply Static para publicarlo en GitHub Pages

## Tecnologías
WordPress · Elementor · CSS3 · Local · GitHub Pages

## Nota
Este repositorio contiene la versión estática de la demo. Los formularios y las funciones dinámicas de WordPress no están activos en esta versión.
